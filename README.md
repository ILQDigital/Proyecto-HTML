# Conquer Blocks - Proyecto HTML

Proyecto de clase de HTML de la escuela Conquer Blocks. Se trata de una web simulada de una plataforma de educación en tecnología con cursos, blog y formularios.

## ¿Qué incluye?

- **Página principal** con presentación de cursos y últimas noticias
- **Catálogo de cursos**: Desarrollo Full Stack e Inteligencia Artificial
- **Blog**: Artículos sobre tecnología, salarios y lenguajes de programación
- **Formularios**: Registro, login y contacto
- **Navegación** en todas las páginas
- **SEO**: Títulos, descripciones y palabras clave personalizadas

```
│   └── lenguajes.html
├── formacion/
│   ├── desarrollo_fullstack.html
│   └── curso_ia.html
└── img/
```

## Cómo usar

1. Descarga o clona el proyecto
2. Abre `index.html` en el navegador
3. Navega por las diferentes páginas usando el menú

## Tecnología

Solo HTML5 - Sin CSS ni JavaScript.
